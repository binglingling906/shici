# 100 首学习目录扩展

本轮将 `content/catalog/phase1-runtime.json` 中的 100 首候选诗升级为可打开、可搜索、可进入学习流程的统一运行时目录。

每首记录现在包含：

- 逐句分段与机器辅助声调拼音（拼音保留为候选状态，未冒充人工审核）；
- 读懂、会意、背诵、复习四段学习契约；
- 关键词、首字提示、无提示背诵和 1/3/7 天复习规则；
- 地点候选、关系类型、主题、年龄范围、课程声明和来源状态。

100 首共享同一关系层：地点/地域、主题、诗人、朝代、体裁、课程册次和“同一条山河”的关联由现有 curriculum/spatial 数据提供。当前 10 首 Phase 1 诗仍是人工完整审核单元，其余 90 首明确标记为 `machine-assisted-candidate`，可先用于探索和学习流程，后续逐首编辑复核。

验收命令：

```bash
npm run check
node scripts/check-100-learning-layer.mjs
```

结果：100/100 记录具备学习契约、拼音 token、关系元数据；原有 Phase 1、空间、课程和体验检查均通过。
