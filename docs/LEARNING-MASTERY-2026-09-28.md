# Learning Mastery First · 交付记录

本轮把诗词学习从“读过/完成”改为可验证的掌握闭环：读懂 → 会意 → 熟背 → 记牢。

## 核心规则

- `completedPoemIds` 只表示今天完成了核心学习，不再代表永久掌握。
- 每首诗有四枚学习印记：读懂印（20%）、会意印（20%）、熟背印（40%）、记牢印（20%）。
- 读懂与会意需要学习者先后提交自己的解释；熟背必须在无提示状态完成一次背诵。
- 记牢印只在已有一次练习、且到达下一次建议复习时间后再次无提示背诵才发放。
- 复习节奏为 1、3、7 天，记录 `count / intervalDays / lastPracticedAt / nextReviewAt`。

## 数据与内容

`content/phase1/mastery-content.js` 为十首 Phase 1 诗提供逐句释义、整首大意、主要内容、情感、中心意思、常见误解、记忆关键词和首字提示；`content/phase1/poems.js` 将其编译为统一 `learningContract`，供阅读、讲解、背诵和评估共用。
