# Project Brief

## 一句话

山河诗境不是古诗资料库，而是一个孩子可以进入、游历、发现，并逐渐建立中国文明连接的世界。

古诗地图是第一扇门，不是最终产品边界。长期方向是 `Chinese Civilization World Model`。

## 第一性体验

第一次打开且没有说明书时，孩子自然产生：“我想点一下这里。”

目前最重要的闭环：

> 进入山河 → 发现地点 → 遇见作品/人物 → 听/看/感受 → 思考 → 自己表达 → 留下探索痕迹 → 自然想继续探索

其中“自然想继续探索”是闭环成立的关键，而不是额外的推荐模块。

## AI Native 的含义

AI 不是传统学习网站右下角的聊天框。它应成为世界回应孩子的机制：理解兴趣和回答、动态解释与追问、调整难度、连接地点/人物/历史、发现误解、帮助表达、组织下一站。

孩子感受到的应该是“这个世界会回应我”，而不是“我正在使用大模型”。

## 儿童学习原则

默认节奏：感受 → 观察 → 猜测 → 提问 → 一点线索 → 再猜 → 自己表达 → 最后解释。

不知道或答得不准确时，优先判断是否应该追问、微提示、讲小故事、换比喻、重新观察或降低难度，不立即给标准答案。

## 体验与视觉边界

声音是潜在的沉浸层，需要实验它是否提升记忆、情绪和在场感。动画可使用云雾、墨迹、水、山、光、风和地图生长，但必须克制并服务叙事。

项目气质来自空间、构图、比例、色彩、材质、字体、声音、节奏和运动，不来自表面古风装饰。

## 现阶段明确不做

- 大而全的诗词数据库、题库或背诵系统
- 登录、支付、会员、权限和运营后台
- 为未来规模预建微服务、大搜索系统或庞大知识图谱基础设施
- 未经验证的历史关系和 LLM 猜测事实
- 为展示技术而加入的 WebGL、3D、聊天框或复杂 Agent 编排
