# 山河诗境 · 书卷式阅读与学习体验升级

## 范围与取舍

沿用 HTML、CSS、原生 JavaScript、既有 hash 路由、100 首运行时目录、17 个概念、地图数据与本地学习记录。首页由地图入口改为今日诗选，地图成为始终可达的探索页；没有增加新诗、新地点、账号或外部服务。

目标年龄继续使用现有 7–8、9–10、11–12 岁阅读方式。阅读为第一层，释义为第二层，概念探索与山风回应为可选的第三层。不是把所有功能同时摆在一张学习卡片上。

## 参考与应用

- [Land-book · Art](https://land-book.com/design/website/art)、[Writing](https://land-book.com/design/website/writing)、[Education](https://land-book.com/design/website/education)：参考内容与图片的编辑式分区、克制留白和细线，不照搬海外字体或装饰。
- [Poets.org](https://poets.org/)：借鉴每日一诗、诗题／作者／正文／朗读的内容顺序，转化为中文诗集首页与阅读页。
- [Mobbin](https://mobbin.com/)：仅研究公开页面可访问的学习、收藏、播放等模式说明；未声称查看登录后完整案例。

采用 frontend-design 和 software-ui-ux-design 的阅读层级、渐进展开、焦点与儿童触控原则。复用项目现有山水图，不新增外部插画请求。

## 页面改动

| 页面 | 本轮设计 |
| --- | --- |
| 今日诗选 `#daily` | 今日诗、真实继续学习、最近读过、三种发现入口；没有记录时显示真实空态 |
| 阅读 `#poem/:id` | 宋体诗文居中、拼音在字上方；桌面正文与山水分栏，手机单列 |
| 学习 | 读与听 → 看懂诗意 → 跟读 → 试着背；切换步骤后将对应内容带入视野 |
| 释义与导师 | 逐句释义紧接正文、赏析与延伸折叠；关键词显示原句与上下文解释，AI 不悬浮覆盖诗文 |
| 背诵 | 遮几个字／遮整句／恢复原文，逐字点击提示；不做未经支持的背诵评分 |
| 诗词本 `#progress` | 最近阅读、收藏、重温、山河足迹；练习计数由用户主动记录，次日提示重温 |
| 发现／地图／挑战／覆盖 | 统一纸色、字体、线条、选中态与触控尺寸；保留现有功能和数据审核边界 |

短诗桌面正文约 30px，手机 24px。词／曲保留来源换行，来源中存在空行时保留分段间距，不凭空推断分阕。拼音开关隐藏注音而保留空间，避免每次开关都推挤正文。

## 设计变量

集中于 `book.css` 的 `:root`：纸色 `#F7F4ED`、正文墨色 `#282B28`、操作绿 `#365C50`、朱红 `#A64B3C`；宋体／黑体字体栈；6–64px 间距刻度；3px 基础圆角；暖灰线条与两级柔阴影。新样式是明确的书卷视觉层，不删除原有空间系统样式。

## 记录与播放

- 保持 `shanhe.phase1.progress` 存储键和版本 2，扩展收藏、最多 12 首最近阅读、逐诗练习次数／时间／下次重温时间。原完成足迹、年龄、拼音偏好、声音、出发城市和挑战记录均保留。
- 练习不等于已掌握；页面明确是“自己记录的练习”，不会自动完成诗词。
- 朗读使用设备 Speech Synthesis。逐句强调只在真实 utterance `onstart` 后出现，没有模拟计时进度条；支持暂停、恢复、停止和失败提示。
- 取消播放会结算旧 Promise；路由切换、步骤切换与后台页面停止朗读，避免旧回调覆盖新页面。
- 异步导师响应核对阅读会话，避免切诗后显示上一首的回应；儿童输入不写入学习记录。
- 本地存储不可访问时降级为当前会话内存，并明确说明不能长期保存。

## 验收记录

实际浏览器完成，而不是只检查截图无报错：

- 1440×900 首页与阅读：诗文完整、辅助图文独立、不重叠；听、拼音、收藏均可操作。
- 390×844 阅读：四句《望庐山瀑布》与常用按钮可见；拼音上置；拼音开关前后正文区域高度一致。
- 1024×768：正文与辅助栏互不覆盖，页面可自然纵向滚动。
- 390×480 输入代理：聚焦文本框后可见，输入／提交／回应正常。此项是矮视口代理，不代替真实 iOS／Android 软键盘设备测试。
- 390×844、150% 根字号：诗文可滚动阅读，无横向溢出；没有通过隐藏页面溢出来掩盖问题。
- 长词《水调歌头》：使用原始行组织，手机可换行，无裁切；缺少校对拼音时明确禁用并显示“拼音校对中”。
- 真实流程：继续学习 → 拼音开关 → 逐句释义／关键词 → 选择“不确定”／微提示／输入回应 → 完成足迹 → 跟读暂停／恢复／停止 → 遮字提示／恢复原文 → 记录练习 → 诗词本 → 刷新后保留。
- 书架：无结果提示与清空操作、搜索诗名、进入阅读、刷新后仍能返回书架。
- 原概念导师：七言绝句的数词选择与下一步骤仍可用。
- 朗读不可用：显示真实不可用提示，不显示假播放或假完成。
- 存储迁移与播放测试：`scripts/check-reading-session.mjs` 覆盖旧记录、收藏、最近阅读、重温、受限 storage、reset 兜底、朗读开始／完成／取消／暂停／错误。

体验检测器仍检查主内容、遮挡、注音对应、字号、触控、输入、认知负担和数据边界。增加滚动与 visualViewport 事件刷新，避免软键盘／自动滚动后沿用旧几何结果。背诵逐字提示按一个操作组计入认知负担，触控目标仍逐个检测 44px。

## 主动 critique 与修正

1. 第一版留白让诗文控制过于靠下：缩减诗题与正文间留白，并压缩手机导航行间距，保留正文 24px。
2. 释义最初在 AI 后：移到诗文后方，解释不用通过提问才能看到。
3. 阶段切换后可能留在旧滚动位置：将阶段对应内容与键盘焦点带入视野，并尊重减少动态设置。
4. 辅助来源在旧移动样式中被隐藏：恢复可展开的来源入口。
5. 搜索、存储受限与朗读失败不能只有空白或假成功：补全真实反馈。
6. 地图碰撞计算曾沿用旧尺寸，且 CSS 点击范围大于计算范围：改为观察实际容器尺寸重新排布，固定真实标记尺寸，完整文字列表保留所有地点。
7. 逐句解释沿用了旧版 12px 小字：放大到约 15px 的黑体与 1.8 行距，不为了把解释塞进一屏而缩小正文。

## 本轮没有伪装完成的部分

- 100 首可读目录不等于 100 首都具备人工校对的逐字拼音与逐句释义。完整策展内容仍以现有 10 首为主，其余显示真实待校对状态；没有自动编造释义或读音。
- 设备语音不是录音棚范读，声音与多音字表现取决于系统语音服务；没有人工录音时间轴，也不显示秒级进度。
- 山风默认使用已有本地诗句引导与已审核概念，不宣称本轮接通新的在线 AI。
- 没有后台推送提醒与跨设备同步；“明天重温”是诗词本里的日期提示。
- 未以这一轮成人操作验收替代真实儿童／亲子可用性测试。
